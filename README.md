A minimalist Python 3.13 entry for make.fun's Fortune Cookies for Machines competition that writes a single-line fortune cookie message for an AI agent to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```
